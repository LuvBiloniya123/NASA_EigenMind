# NASA_EigenMind

## SI-Powered Microgravity Fire Safety Intelligence Dashboard

**NASA Space Apps Challenge 2026**

EigenMind is an interactive, SI-powered research and decision-support dashboard designed to explore NASA microgravity combustion investigations and spacecraft fire-safety challenges.

### Key Features
1. Mission Environment Simulator
2. NASA PSI Investigation Explorer
3. Investigation Comparison
4. SI Research Knowledge Engine
5. Evidence and Data Quality Analysis
6. Machine-Learning Analysis and Visualizations

### Technology Stack
Python, Streamlit, Pandas, NumPy, Scikit-learn, Plotly and ReportLab.

### Scientific Limitations
EigenMind is an exploratory research prototype, not a validated spacecraft fire-prediction system. Synthetic or project-defined model targets and scenario scores are illustrative and must not be interpreted as experimentally validated fire-risk probabilities or operational safety limits.
